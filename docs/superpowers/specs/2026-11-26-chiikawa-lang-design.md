# chiikawa-lang 설계

날짜: 2026-11-26

## 의도

치이카와 밈으로 만든 비공식 장난감 프로그래밍 언어. 코드가 캐릭터들의 울음소리와 말버릇으로만 이루어져 있어서, 읽으면 웃기고 직접 짜기는 어려운 난해한 언어(esolang)다. 터미널에서도 돌아가고, 링크 하나로 남에게 보여줄 수 있어야 한다.

## 목표 / 비목표

- 목표: 한국어 밈 대사만으로 된 튜링 완전 언어, CLI(파일 실행·REPL), 브라우저 플레이그라운드, 사람이 직접 못 짜는 문제를 풀어주는 "문장 → 코드" 생성기.
- 비목표: 실용적인 언어 기능(변수, 함수, 타입), 성능, 일본어 키워드, 에디터 플러그인.
- 하면 안 되는 것: 원작 그림·로고·캐릭터 이미지 사용, 공식 작품처럼 보이는 표현. README와 플레이그라운드에 비공식 팬 작품임을 밝힌다.

## 접근 방식

1. **Brainfuck 계열 + 늘여 말하기 (선택)**: 울음소리 8개가 Brainfuck 명령 8개에 하나씩 대응하고, 소리를 늘이면 그만큼 반복된다(`야하하하` = +3). 튜링 완전성이 보장되고, 기존 Brainfuck 프로그램을 그대로 옮길 수 있고, 울음소리와 동작이 1:1이라 외우기 쉽다.
2. Ook! 스타일: `우라`·`야하`·`와` 세 개를 두 개씩 묶어 명령 8개를 만든다. 더 "울음소리뿐"이지만 코드가 두 배로 길어지고 소리와 뜻이 연결되지 않는다.
3. 스택 기반 언어: 더 독창적이지만 숫자 넣기·연산·복제·점프 등 명령이 많이 필요해서, 널리 알려진 대사 수보다 키워드가 많아진다.

## 언어 명세

메모리는 0으로 채워진 칸 30,000개(칸 하나는 0~255, 넘치면 돌아감)와 0번 칸에서 시작하는 포인터 하나다.

| 울음소리 | 누구 | 동작 | 늘여 말하기 | Brainfuck |
|---|---|---|---|---|
| `야하` | 우사기 | 현재 칸 +1 | `야하하하` = +3 | `+` |
| `싫어` | 치이카와 | 현재 칸 −1 | `싫어어어` = −3 | `-` |
| `우라` | 우사기 | 포인터 오른쪽으로 | `우라라라` = 3칸 | `>` |
| `후웅` | 우사기 | 포인터 왼쪽으로 | `후우우웅` = 3칸 | `<` |
| `와` | 치이카와 | 현재 칸을 글자(바이트)로 출력 | `와아아` = 3번 | `.` |
| `하?` | 우사기 | 입력 1바이트를 현재 칸에 (입력 끝이면 0) | `하아아?` = 3번 | `,` |
| `라는 거?!` | 하치와레 | 현재 칸이 0이면 짝이 되는 `어떻게든 돼라` 뒤로 건너뜀 | – | `[` |
| `어떻게든 돼라` | 하치와레 | 현재 칸이 0이 아니면 짝이 되는 `라는 거?!` 뒤로 돌아감 | – | `]` |
| `울어버렸다` | 하치와레 | 프로그램 즉시 종료 | – | 없음 |

- 울음소리 사이는 공백이나 꾸밈 문장부호(`!` `~` `…` `.` `,` `♪`)로 구분한다. 꾸밈 부호는 무시된다.
- `#`부터 줄 끝까지는 주석이다.
- 그 밖의 글자는 전부 오류다. "치이카와"에도 `와`가 들어 있어서, 모르는 글자를 무시하면 주석이 실행돼 버리기 때문이다.
- 표기 변형 허용: `라는거?!`, `라는 거!?`, `어떻게든돼라`, `어떻게든 되어라`.
- 출력은 바이트 단위이고 UTF-8로 해석한다. 한글도 출력할 수 있다.
- 오류(모르는 울음소리, 짝 안 맞는 반복, 테이프 범위 이탈)는 줄·칸 위치와 함께 "울어버렸다…!"로 시작하는 메시지를 낸다.

## 구성

- `src/core.ts`: 의존성 없는 순수 모듈 하나. 해석(`parse`), 실행기(`Machine`, 정해진 걸음 수만큼 실행하고 멈췄다 이어갈 수 있음), `fromBrainfuck`, 문장을 코드로 바꾸는 `encodeText`.
- `src/cli.ts`: `chiikawa run <파일>`, `chiikawa repl`, `chiikawa encode <문장>`, `chiikawa from-bf <파일>`.
- 플레이그라운드: 한 파일짜리 정적 HTML(`docs/index.html`). 빌드 스크립트가 컴파일된 core를 템플릿에 끼워 넣는다. 편집기, 실행/정지, 입력, 출력, 테이프 보기, 예제, 문장 → 코드 생성기, 울음소리 표.
- `examples/*.chiikawa`, `test/*.test.ts`(node:test), 한국어 README.

## 내가 정한 것 (사용자가 고른 게 아님)

- TypeScript, Node 22.18 이상. 런타임 의존성 없음, 개발 의존성은 `typescript`와 `@types/node`.
- 파일 확장자 `.chiikawa`.
- 칸 30,000개·8비트·입력 끝 = 0 (Brainfuck 관례).
- 모르는 글자는 무시하지 않고 오류.
- 무한 반복 대책: 플레이그라운드는 조금씩 나눠 실행해서 정지 버튼이 먹히게 한다. CLI는 Ctrl-C.
- 라이선스는 정하지 않는다(저장소 주인이 정할 일).
