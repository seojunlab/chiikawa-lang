# chiikawa-lang

치이카와 친구들의 울음소리만으로 짜는 장난감 프로그래밍 언어입니다. Brainfuck 계열의 난해한 언어(esolang)라서 읽으면 웃기고 직접 짜기는 어렵습니다.

> 비공식 팬 작품입니다. 「치이카와」와 등장 캐릭터의 권리는 원작자 나가노와 각 권리자에게 있고, 이 프로젝트는 그들과 관계가 없습니다. 원작의 그림은 쓰지 않았습니다.

## 맛보기

글자 `A` 하나를 출력하는 프로그램입니다.

```
야하하하하하하하하            # 0번 칸 = 8
라는 거?!                    # 0번 칸이 0이 아니라는 거?!
  우라 야하하하하하하하하     # 옆 칸으로 가서 +8
  후웅 싫어                  # 돌아와서 -1
어떻게든 돼라~!              # 0이 될 때까지 반복
우라 야하 와!                # 64 + 1 = 65, 글자 "A"
```

## 울음소리

칸 30,000개가 한 줄로 늘어선 테이프와, 그중 한 칸을 가리키는 포인터가 있습니다. 모든 칸은 0에서 시작하고 포인터는 0번 칸에서 시작합니다. 칸에는 0부터 255까지 들어가고 넘치면 돌아갑니다(255 + 1 = 0).

| 울음소리 | 누가 | 하는 일 | 늘여 말하면 | Brainfuck |
|---|---|---|---|---|
| `야하` | 우사기 | 지금 칸에 1을 더한다 | `야하하하` = +3 | `+` |
| `싫어` | 치이카와 | 지금 칸에서 1을 뺀다 | `싫어어어` = −3 | `-` |
| `우라` | 우사기 | 오른쪽 칸으로 간다 | `우라라라` = 3칸 | `>` |
| `후웅` | 우사기 | 왼쪽 칸으로 간다 | `후우우웅` = 3칸 | `<` |
| `와` | 치이카와 | 지금 칸을 글자로 말한다(출력) | `와아아` = 3번 | `.` |
| `하?` | 우사기 | 입력에서 한 글자를 지금 칸에 받는다. 입력이 끝났으면 0 | `하아아?` = 3번 | `,` |
| `라는 거?!` | 하치와레 | 지금 칸이 0이면 짝이 되는 `어떻게든 돼라` 뒤로 건너뛴다 | | `[` |
| `어떻게든 돼라` | 하치와레 | 지금 칸이 0이 아니면 짝이 되는 `라는 거?!` 뒤로 돌아간다 | | `]` |
| `울어버렸다` | 하치와레 | 프로그램을 바로 끝낸다 | | 없음 |

규칙은 몇 개 없습니다.

- 울음소리 사이는 띄어 씁니다. `우라라는 거?!`처럼 붙여 쓰면 오류입니다.
- `!` `~` `…` `.` `,` `♪`는 꾸밈이라 어디에 붙여도 무시됩니다. `야하하하! 우라~♪ 와…`는 `야하하하 우라 와`와 같습니다.
- `#`부터 줄 끝까지는 주석입니다.
- 그 밖의 글자는 전부 오류입니다. "치이카와"라는 말에도 `와`가 들어 있어서, 모르는 글자를 그냥 넘기면 주석이 실행돼 버리기 때문입니다.
- `라는거?!`, `라는 거!?`, `어떻게든돼라`, `어떻게든 되어라`처럼 써도 됩니다.
- 입출력은 바이트 단위(UTF-8)입니다. 한글 한 글자는 3바이트라서 `와`를 세 번 해야 한 글자가 나옵니다.

오류가 나면 위치와 함께 울어버립니다.

```
울어버렸다…! 2번째 줄 3번째 글자: 모르는 울음소리 "냐옹"
```

## 플레이그라운드

`docs/index.html`을 브라우저로 열면 설치 없이 바로 써 볼 수 있습니다. 울음소리 자판으로 코드를 찍고, 실행 결과와 테이프 상태를 보고, 문장을 넣어 그 문장을 말하는 코드를 만들 수 있습니다. 끝나지 않는 프로그램은 정지 버튼으로 멈춥니다.

파일 하나로 되어 있어서 GitHub Pages로 올리기도 쉽습니다. 저장소 Settings → Pages에서 배포 원본을 기본 브랜치의 `/docs` 폴더로 고르면 됩니다.

## 터미널에서 쓰기

Node.js 22.18 이상이 필요합니다. 설치 없이 바로 실행할 수 있습니다.

```sh
node src/cli.ts examples/hello.chiikawa
# Hello, World!
```

`chiikawa` 명령으로 쓰려면 빌드해서 연결합니다.

```sh
npm install
npm run build
npm link
```

```sh
chiikawa run examples/countdown.chiikawa      # 프로그램 실행. run은 빼도 됩니다
# 9 8 7 6 5 4 3 2 1 0

echo "우라! 야하!" | chiikawa run examples/cat.chiikawa   # 표준 입력이 하?로 들어갑니다
# 우라! 야하!

chiikawa encode "안녕" > annyeong.chiikawa    # 문장을 말하는 프로그램 만들기
chiikawa run annyeong.chiikawa
# 안녕

chiikawa from-bf program.bf                   # Brainfuck 프로그램 옮기기
chiikawa repl                                 # 한 줄씩 실행
```

REPL은 줄마다 실행하고 테이프와 포인터를 다음 줄로 이어 갑니다. `울어버렸다`나 Ctrl-D로 끝냅니다. `하?`는 그다음에 치는 줄에서 읽고, 읽고 남은 부분은 버립니다.

```
ㅊㅋ> 야하하하
[0번 칸 = 3]
ㅊㅋ> 우라 야하
[1번 칸 = 1]
```

## 예제

| 파일 | 하는 일 |
|---|---|
| `examples/hello.chiikawa` | `Hello, World!` |
| `examples/annyeong.chiikawa` | `안녕, 치이카와!` |
| `examples/cat.chiikawa` | 입력을 그대로 따라 말한다 |
| `examples/reverse.chiikawa` | 입력을 거꾸로 말한다 |
| `examples/countdown.chiikawa` | 9부터 0까지 센다 |
| `examples/triangle.chiikawa` | 별로 삼각형을 그린다 |

## 개발

```sh
npm install
npm test            # node:test, 의존성 없이 .ts를 바로 실행
npm run typecheck
npm run build       # dist/ 와 docs/index.html 을 다시 만든다
```

- `src/core.ts`: 해석기 전체. 아무것도 import하지 않아서 브라우저에서도 그대로 돕니다.
- `src/cli.ts`: 터미널용 명령.
- `playground/index.html`: 플레이그라운드 템플릿. `npm run build`가 여기에 core와 예제를 끼워 넣어 `docs/index.html`을 만듭니다. 템플릿이나 `src/core.ts`, 예제를 고쳤으면 다시 빌드해서 `docs/index.html`도 같이 커밋하세요.
